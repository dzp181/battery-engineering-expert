# 电池工程专家（Battery Engineer）

锂电电芯全流程工程专家：从材料体系选型、极片配方与容量设计，到制成工艺、化成老化、失效分析和安全认证排障。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **电芯设计与参数计算**：面容量、面密度、N/P 比、压实与孔隙率、注液量、层数与能量密度，输出可执行的设计参数表。
- **材料体系选型**：LFP / LMFP / NCM / NCA / LCO / LMO 正极，石墨 / SiOx / Si-C 负极，电解液添加剂、隔膜、导电剂与粘结剂路线对比。
- **制程工艺调机**：匀浆、涂布、辊压、分切模切、卷绕叠片、焊接、封装、注液、化成、抽气封口、分容分选的问题定位。
- **化成老化与标定**：化成工步设计、老化窗口、自放电 K 值筛选、DCIR/ACIR、容量分档与 SOC-OCV 标定。
- **失效分析**：析锂、胀气、容量跳水、内阻上升、自放电偏大、内短路、热失控的原因树与拆解验证方案（SEM/EDS、XRD、XPS、ICP、CT、EIS、ARC、GC）。
- **安全与认证**：GB 38031、GB 31241、UN38.3、IEC 62133-2、UL 1642/2054、UL 9540A 的失效模式与整改方向。
- **PACK 与量产**：串并联一致性、BMS 匹配、热管理、膨胀力、良率与 CPK、成本拆解。

## 使用示例

- 我要做一款 280Ah 磷酸铁锂储能电芯，帮我从正极面容量、N/P 比到注液量把关键设计参数算一遍。
- 这批电芯化成后自放电偏大、部分出现胀气，帮我按可能性排序排查原因并给出验证顺序。
- 循环 800 周后容量衰减到 80%、DCIR 明显上升，帮我判断是析锂、SEI 增厚还是电解液消耗，并给出拆解验证方案。

## 安装

将专家包目录放到专家目录下：

```
/Users/dzp/.workbuddy/plugins/marketplaces/my-experts/plugins/battery-engineering-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
